MON COACH FITNESS — V12 — MISE À JOUR SÉCURISÉE

Cette archive conserve les fonctionnalités et le design de la V10.

Améliorations incluses :
- Conserve le comportement V10 : enregistrement d'une séance puis ouverture de « Mes progrès ».
- Complète la liste des exercices officiels absents sans remplacer les exercices déjà enregistrés ni supprimer les exercices personnalisés.
- Uniformise les libellés de jours/séances pour l'affichage dans « Ma séance ».
- Aligne le regroupement de « Programme complet » sur la même normalisation des jours.
- Enregistre les nouvelles données dans mcf_state_v11 après avoir chargé les données déjà présentes sous mcf_state_v7, v6, v5, v4 ou v3.
- Actualise la stratégie du service worker en V12 : réseau prioritaire pour les fichiers, cache de secours hors connexion, prise de contrôle des onglets et nettoyage limité aux caches « mcf- ».
- À la première ouverture, copie l’état chargé depuis V7/V6/V5/V4/V3 vers mcf_state_v11 sans supprimer ni modifier les anciennes clés.
- Corrige la lecture des sauvegardes : une clé ancienne invalide n’empêche plus de charger une autre sauvegarde valide.

IMPORTANT :
1. Avant l'installation, utilise « Mes progrès » > « Exporter mes données ».
2. Décompresse l'archive.
3. Remplace dans le dépôt GitHub les fichiers correspondants : index.html, service-worker.js, manifest.webmanifest, icon-192.png et icon-512.png.
4. Fais Commit changes et attends la fin du déploiement GitHub Pages.
5. Ferme les onglets de l'application puis rouvre le site. Si une PWA est déjà installée, ouvre aussi le site dans Chrome pour vérifier la nouvelle version.

Les données de sport restent dans le stockage local du navigateur. L'export JSON préalable est indispensable par prudence. La synchronisation entre appareils n'est pas fournie par GitHub Pages.
